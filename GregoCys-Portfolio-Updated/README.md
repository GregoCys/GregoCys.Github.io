# GregoCys.com — Updated Portfolio

Static, responsive HTML/CSS/JavaScript site for GitHub Pages. No build tools required.

## Publishing
1. Back up the existing repository and GitHub Pages settings.
2. Copy the **contents** of this archive into the repository root, replacing the older HTML/CSS while retaining any unrelated assets you still need.
3. Commit and push to the branch configured under **Settings → Pages**.
4. Confirm the custom domain DNS and the repository CNAME setting still point to `www.gregocys.com`.

## Site pages
- `index.html`: home
- `about.html`: biography
- `skills.html`: experience and technical capabilities
- `certifications.html`: credentials and education
- `portfolio.html`: projects
- `GregoGaurd.html`: research hub (original misspelled route kept for compatibility)
- `GregoGuard.html`: forward-link alias
- `research-crackme.html` and `research-file-parser.html`: project case studies
